TrustCore ● live

Challenge 1 — The Agent That Earns Trust. Verifiable credentials (Ed25519, VC-shaped), deterministic policy gating, append-only decision receipts. No LLM on the enforcement path.

Try it:

  • GET /api/trust/agents — registered agents
  • GET /api/trust/receipts — decision receipts (allow / refuse, llm_called=false)
  • GET /api/trust/profile?subject_key=<base64-key> — trust profile per agent
  • GET /docs — interactive API (decide / issue / revoke)
