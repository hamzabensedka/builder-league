Beyond the Chatbot
What replaces the dashboard and chatbot in an AI-native world?

Brief
Overview
The dashboard and the chatbot are the wrong default interfaces for AI-native work. Pick one real workflow and design the interface that replaces both.

What you'll build
A non-chat, non-dashboard interface for one real workflow (your pick, sales, support, ops, design, code, whatever)
The UI surfaces only what the user needs to decide next, not a wall of data
At least one action the interface initiates on its own, with human review
Side-by-side with a "what this replaces" screenshot so the contrast is clear
Deliverables
Working build (repo + live demo or recorded walkthrough)
90-second Loom showing the workflow start to finish
Architecture snapshot: data → intent inference → surfaced decision → action
A failure test: when the interface guesses wrong, what's the recovery path?
Two-year thesis (≤300 words) on post-chatbot AI interfaces
Why it matters
Chat is a fallback when the system doesn't know what you need. Build the system that does.

Requirements
Submission checklist
Public repo URL (clean clone runs)
Live demo URL (required): a working link anyone can open
90-second Loom or video walkthrough (optional, but recommended)
Notes: AI tools used, key decisions, out of scope
How you'll be measured
Weight	Criterion	What we look for
25	Conceptual clarity	The interface obviously beats chat+dashboard for this job.
25	Technical depth	Real intent inference, not hardcoded flows.
20	Demo quality	The "wow" is felt in the first 30 seconds.
15	Failure thinking	Wrong-guess recovery is graceful.
15	Future thesis	Strong view on AI-native UI patterns.
Bonus signals
Works on a real dataset, not lorem ipsum
Designed for an actual job, not a hackathon toy
Disqualifications
It's a chatbot in a fancy wrapper
It's a dashboard with an "Ask AI" button
No demo
